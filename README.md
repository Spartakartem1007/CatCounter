# CatCounter
# CatCounter 🐱

**Русский**  
Программа для учёта ухода за котом. Отмечайте кормление, сон, игры — программа ведёт статистику и сохраняет её. Внутри есть мини-игры: рыбалка и угадай число. Поддерживает русский и английский язык. Работает на Windows.

**English**  
Cat care tracker app. Mark feeding, sleep, play — the app keeps statistics and saves data. Includes mini-games: fishing and guess the number. Supports Russian and English. Works on Windows.

---

## Возможности / Features

-  Учёт еды / Food tracking
-  Учёт сна / Sleep tracking
-  Учёт игр / Play tracking
-  Мини-игра «Рыбалка» / Fishing mini-game
-  Мини-игра «Угадай число» / Guess number mini-game
-  Автосохранение / Auto-save
-  Русский / English

---

## Запуск / How to run

**Windows:**  
Запустите `CatCounter.exe`  
Run `CatCounter.exe`
