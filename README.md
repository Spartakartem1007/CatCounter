# CatCounter
Программа для учёта ухода за котом. Отмечайте кормление, сон, игры. Программа ведёт статистику, сохраняет данные, имеет мини-игры (рыбалка, угадай число). Работает на Windows.  Cat care tracker app. Mark feeding, sleep, play. Keeps statistics, saves data, includes mini-games (fishing, guess number). Works on Windows.
